# Java CC

## How to run :

`javacc <file.jj>`

Then compile the generated java files

`javac *.java`

Finaly run the executable :

`java <MainClass name> [args]` for example `java Minicompilador prueba.txt`
where prueba.txt is the args to be passed to the programm

## Extra
Additionally, i created a script to clean all the javacc verbose stuffs

Run :

`remove_javacc_garbage.bat` in windows to remove those files before compiling again
